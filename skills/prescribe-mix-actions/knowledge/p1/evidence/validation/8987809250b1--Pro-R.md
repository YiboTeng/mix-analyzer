# FabFilter Pro-R 1.1.5：默认全湿脉冲验证

## 结论

本机 Pro-R 1.1.5 VST3 在 Ableton Live 11.3.43 中以 Default Setting、Mix 100%、Space 2.50 s、Predelay 0.6 ms 处理固定脉冲。首脉冲检测起音 7.292 ms、拟合 T60 2.1497 s；三次拟合 2.1497/2.1129/2.1394 s。Correlation -0.018777、Side/Mid +0.1632 dB，说明默认状态生成宽且 Side 略高于 Mid 的尾部。

## 固定条件与结果

- 输入/对照：`impulse_train_48k.wav`；共享旁通 `a0c159c0ffd1--impulse--bypass.wav`。
- 插件状态：Default Setting；Space 2.50 s；Decay Rate 100%；Mix 100%（锁定）；Predelay 0.6 ms；其余 Brightness、Character、Distance、Stereo Width 与 Decay Rate EQ/Post EQ 保持默认界面状态。
- 渲染：Master，6 s，48 kHz、24-bit WAV、Triangular dither；工程快照 `validation/host/snapshots/8987809250b1--Pro-R.als`。

## 使用动作与边界

- Default 2.5 s 会形成宽尾；连续 Rap 主唱上先缩 Space/Decay，再用 Predelay 和 Distance 保留字头。
- 默认相关性略为负且 Side/Mid 为正，Mono 下尾部可能明显改变；Aux 返回必须做 Mono Fold-down。
- 界面 Predelay 0.6 ms 与检测 onset 7.292 ms 不相等，后者还包含算法建立与检测阈值；不能把它解释为 PDC。
- 未做听感等响；onset、衰减和相关性不依赖整体增益，Peak/RMS 只记录条件。
- 只验证 Default Setting，不外推 Decay Rate EQ、Post EQ、其他 Character/Distance 或 Studio One 行为。
