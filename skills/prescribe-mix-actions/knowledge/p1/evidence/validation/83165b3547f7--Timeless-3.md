# Timeless 3 3.0.5：默认双延迟与全湿路由验证

## 结论

本机 FabFilter Timeless 3 3.0.5 VST3 在 Ableton Live 11.3.43、Host 160 BPM、Default Setting 下，左右手动延迟显示为 350.0/353.5 ms。将插件原生 `MIX` 环明确设为 100% 后，首脉冲左右首个湿声分别出现在 350.229/353.729 ms，准确复现 3.5 ms 的左右偏移；合并包络的首个重复为 353.229 ms。后四个重复间隔为 352.792、351.958、352.604、353.021 ms，反馈峰值从 -18.4448 dBFS 依次衰减到 -60.6956 dBFS。

## 固定状态与量化

- A（插入默认对照）：Default Setting；Delay L/R=350.0/353.5 ms；插件原生 Mix=0%；Width=100%；其余默认。
- B（全湿处理）：同 A，仅将插件原生 `MIX` 环设为 100%；未启用额外 Tap、FX 或调制。
- 输入：固定 `impulse_train_48k.wav`；渲染 Master、6 s、48 kHz/24-bit WAV、Triangular dither。
- 工程快照：`validation/host/snapshots/83165b3547f7--Timeless-3.als`。

## 使用动作与副作用

- Default Setting 的插件原生 Mix 是 0%，所以默认插入渲染保留满电平干脉冲；做 Send/Aux 时必须拖动主旋钮右侧细小的 `MIX` 环到 100%，不能把 Ableton 设备壳显示的 `Mix 100%` 当作原生 Mix 的证明。
- 350.0/353.5 ms 形成 3.5 ms 固定左右错位；本次全湿声 Correlation 0.809、Side/Mid -9.77 dB，宽度明显高于 H-Delay 默认的近中心 Tap。若主唱中心稳定性优先，应监听 Mono 并缩小左右时间差或 Width。
- 默认反馈每轮约下降 9–13 dB，五次内从 -18.44 降至 -60.70 dBFS；这是当前默认状态的观测，不外推改变 Feedback、Cross Feedback、滤波或非线性 FX 后的衰减。
- 后两个输入脉冲与前一脉冲尾部重叠，因此时间与衰减结论只采用第一个脉冲窗口；后续窗口仅证明尾部会跨越下一事件，不用于拟合独立反馈曲线。
- 本测试未开启 Taps、Drive、Lo-Fi、Diffuse、Dynamics、Pitch、调制、Freeze 或 Feedback>100%；Auto Mute Self-Osc 只观察到界面入口，未做失控反馈安全试验。
- 效果重复的约 350 ms 不是插件 PDC；本工程状态显示宿主报告 Latency 0 samples，但该信息不替代跨宿主测量。
