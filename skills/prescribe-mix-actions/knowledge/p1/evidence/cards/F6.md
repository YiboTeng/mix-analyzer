# F6

## 身份与版本

- 厂商：Waves
- 产品族：F6
- Family ID：5cc7ad8baf95
- 本机观测版本：12.7.0.209
- 格式：VST2 | VST3
- Studio One 可用性：current-filesystem-match
- 主能力方向：eq-dynamic-flexible
- 次能力方向：external-sidechain;mid-side
- 当前证据等级：L3
- 验证状态：passed

## 能做什么

- 六个可自由定位的参数频段，每段同时提供静态 EQ 与向上/向下动态处理。
- 支持 M/S、外部侧链、频谱分析和每段独立监听，适合人声共振、低中频和伴奏遮蔽控制。

## 不建议用来做什么

- 不要把所有齿音和共振都交给多个深窄动态带。
- 不要在未匹配输出响度时把削减后的清晰误判为更好。

## 信号流位置

- 修正型静态 EQ 之后或压缩之后处理音素相关共振。
- 外部侧链时放在需要给主唱让位的伴奏总线上。

## 控制语义

| 控制 | 含义 | 调整动作 |
|---|---|---|
| Freq/Q/Gain | 频段中心、带宽和静态增益。 | 先用窄带监听定位，再放宽到不损伤元音。 |
| Range/Threshold | 动态最大幅度和触发点。 | 先限定 Range，再下调 Threshold 到只在问题音素动作。 |
| Attack/Release | 动态段进入和恢复速度。 | 以辅音保留和无泵动为停止条件。 |
| SC/M-S/RTA | 侧链来源、通道模式与频谱反馈。 | 按任务选择，不把显示峰值直接等同听觉问题。 |

## Gain Staging

处理前后以短时 RMS 或 LUFS-S 匹配，记录每段最大动态增益和总输出修正。

## 延迟、相位与过采样

静态与动态滤波都会改变频率相关相位；本机 VST3 Stereo、48 kHz、当前 Full Reset/单段设置宿主报告 `0 samples`。这不代表所有格式、采样率、路由或自动化状态都零延迟。

## Mono/Stereo

主唱常用 Stereo 实例但以 Linked/Mid 为基线；M/S 动态带必须检查 Mono Fold-down。

## 适用场景

- 压缩后控制 2–5 kHz 随音素冒出的硬度。
- 伴奏总线上由主唱侧链触发让位。

## 路由

- 主唱 Insert。
- 伴奏总线 External Sidechain。

## 参数起点

- Range 先限制在 1–3 dB，再寻找 Threshold；Range 是最大动态边界，不是必然发生的 GR。
- Attack 5–30 ms、Release 60–200 ms 作为人声起点并按听感修正。

## 调整目标

- 问题音素出现时动作，正常元音基本不动。
- 旁通等响后清晰度提高但不变薄。

## 调整时听什么

- 辅音被吸走、元音发空、释放泵动。
- M/S 处理造成中心漂移。

## 何时停止

- 最大动态量已受 Range 限制且问题刚好退后。
- 再增加处理开始损害咬字或稳定性。

## 常见失败

- 用过窄 Q 追着频谱峰值跑。
- 外部侧链未检查延迟与通道映射。

## 替代方案

- Pro-Q 3：更完整的手术式可视化。
- soothe2：更自动化的动态共振抑制。

## 专业案例与工作流线索

- 官方将其定位为六段浮动动态 EQ，并强调每段压缩/扩展、M/S 与外部侧链。

## 待执行测试

- 真实人声/伴奏外部侧链测触发、释放、泵动和旁通等响。
- M/S、Link、Wide、Global Release、向上扩展与其它 Band/滤波形状矩阵。

## 已测结果

- 本机 Waves `F6 Stereo` V12（文件系统 `12.7.0.209`）在 Ableton Live 11.3.43、48 kHz 中真实加载；Full Reset 六段平直、Mix 100、Output 0、Stereo、Internal、Split，宿主报告 `0 samples`。
- Full Reset 对共享旁路在 0–6、8–20、66–72 秒三个区域均约 `0.000000 dB`，相关约 `1.0`，残差约 `-141.4 dBFS`；当前起点可视为中性。
- 静态 Band 1 Bell：`1736 Hz / Q 1.0 / Gain +3.7 dB / Range 0`。稳定十音整体 `+0.260271 dB`，1760 Hz `+1.528927 dB`，并有频率相关相位变化；同时多音结果不能等同单独正弦扫频。
- 动态 Band 1：`1736 Hz / Q 1.0 / Gain 0 / Range -4.3 dB / Threshold -53.6 dB / Attack 16 ms / Release 160 ms / Internal / Split`。稳定十音整体 `-0.106428 dB`，1760/3520 Hz 约 `-0.671908/-0.672974 dB`；三个低电平短事件仅约 `-0.000119` 至 `-0.000265 dB`，证明动作依赖内容与检测电平。
