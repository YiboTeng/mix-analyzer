# 把人声不干净拆成房间声、高频毛边与动态刺耳

## 结论

“脏”不是一个频率名称。先把问题拆成房间尾巴、持续的宽带高频粗糙、由辅音触发的齿音、以及只在某些字冒出的动态刺耳，再分别选择去混响、高频平滑、De-Esser 或多段／动态 EQ。低端的宽曲线塑形应放在清理之后，不能掩盖录音端问题。

## 判断顺序

```text
人声不干净
  ├─ 停顿和尾音仍有房间尾巴 → 轻量去混响
  ├─ 整段高频砂、硬、粗 → 高频平滑／共振抑制
  ├─ s、sh 等辅音才刺 → De-Esser
  └─ 只有某些字或音高刺 → 多段／动态 EQ 向下压缩
```

## 操作原则

- 去混响先于精细动态处理，否则房间反射会持续触发后级。
- 宽带粗糙和齿音不是同一对象；避免用一个宽频 De-Esser 把整条人声压暗。
- 动态刺耳频段应只在异常出现时收紧；长一点的 Release 可减少增益衰减抖动，但过长会让后续正常字也被压住。
- Pultec 式同频 Boost／Atten 利用不同曲线形成宽峰谷；`100 Hz` 只是一个示例起点，不是所有人声的固定处方。
- 每步等响旁路，并监听伪影、变薄、齿音残留与低端闷糊。
