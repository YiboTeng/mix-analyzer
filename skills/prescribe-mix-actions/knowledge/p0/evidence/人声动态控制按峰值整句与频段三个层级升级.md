# 人声动态控制按峰值、整句与频段三个层级升级

人声动态问题应按时间和频率尺度分层：快速压缩器抓瞬时峰值；Clip Gain、Rider 或慢速压缩整理句子内部电平；多段压缩或动态 EQ 只处理特定频带偶发堆积。每增加一级，都必须说明上一层为什么不能完成任务。

基础层用 Attack 决定保留多少咬字，用 Release 决定回弹与贴近感；整句层减少小声字迫使峰值压缩器持续深压；选频层先逐段旁路再启用，只在问题出现时工作。最后逐级旁路、等响，并检查呼吸、辅音、句尾与底噪是否被抬升。
