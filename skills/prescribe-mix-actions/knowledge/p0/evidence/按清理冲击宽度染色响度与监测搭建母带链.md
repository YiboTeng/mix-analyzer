# 按清理、冲击、宽度、染色、响度与监测搭建母带链

## 结论

母带链应按问题分工，而不是按插件清单堆叠。一个可复用的顺序是：先清理和校正整体频谱，再塑造冲击与声场；需要时增加清晰度、动态频谱约束和模拟染色；最后让削波器与真峰值限制器分担响度任务，并用独立监测验证结果。

```text
清理 → 静态平衡 → 冲击 → 宽度 → 可选清晰度
→ 动态频段控制 → 染色 → 选择性拓宽
→ 削波 → 真峰值限制 → 监测
```

## 使用原则

- 每个模块必须对应一个已听见或已测量的问题；没有问题就旁路。
- 所有 A/B 比较都要做响度匹配，避免把“更响”误判为“更好”。
- 宽度优先放在中高频，低频维持稳定中心，并检查单声道兼容。
- 清晰度类处理是可选项；变刺耳、变薄或齿音被放大时，应减弱或移除。
- 削波器负责极短峰值，限制器负责最后的响度与真峰值上限，不要让单个处理器承担全部增益衰减。
- 监测器放在最后且不改变声音；最终判断仍需结合参考曲和多种播放环境。

## 最小实现

1. 校正明显的低频垃圾与整体倾斜。
2. 只在需要时调整瞬态和多段宽度。
3. 用动态 EQ 控制偶发刺耳或频段堆积。
4. 少量饱和增加密度和谐波。
5. 轻度 Clipping 后接 True Peak Limiting。
6. 检查响度、真峰值、动态、频谱、相位相关度与单声道折叠。
