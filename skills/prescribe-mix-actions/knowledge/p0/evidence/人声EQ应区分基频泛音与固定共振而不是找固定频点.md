# 人声EQ应区分基频泛音与固定共振而不是找固定频点

频段图只能提供听感假设，不能替代判断。人声中的明显峰值可能是随音高移动的基频／泛音、长期停在同一位置的录音链或房间共振，也可能只在某些字与音符上偶发；三者不应使用同一种 EQ 处理。

## 判断顺序

1. 先听完整乐句和伴奏，描述问题是轰、浑、箱、鼻、硬、刺、齿还是缺空气感。
2. 到对应候选频区短暂夸张以确认，随后恢复到零；不要把听辨时的极端曲线保留下来。
3. 观察峰值是否随旋律移动：随音高移动的更可能是音乐性基频或泛音，长期固定且跨音符异常突出的才更像静态共振。
4. 持续问题可小幅静态处理；只在特定字、音符或响度下出现的问题，使用动态 EQ 或自动化。
5. 在整句、伴奏中做等响旁路。若没有明确改善，或该频区没有突出问题，就不处理。

100 Hz 的厚度、200 Hz 的温暖、300–500 Hz 的主体／箱体感、1–2 kHz 的中频骨架与存在感、5 kHz 的咬字、7–10 kHz 的光泽、12 kHz 以上的空气感，都只是常见听感入口。歌手音域、元音、麦克风、距离、房间和编曲会移动实际位置；性别标签和固定频点不能构成处方。

低切也遵循同一原则：只移除喷麦、振动和无音乐意义的次低频，截止点应在当前素材上听证。高频提升则要同时检查齿音、底噪和房间声。
