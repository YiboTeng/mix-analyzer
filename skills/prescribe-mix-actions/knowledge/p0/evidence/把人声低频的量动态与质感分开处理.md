# 把人声低频的量、动态与质感分开处理

## 结论

人声低频“糊”时，先判断是长期能量过多、局部动态冒出，还是削减后缺少质感。静态 EQ 管长期倾斜，动态 EQ／多段压缩管偶发过量，饱和／失真负责在不补回大量低频的前提下增加可感知密度。

```text
人声低频听起来糊
  ├─ 全程持续偏多 → 低架／温和低切校正“量”
  ├─ 少数字句突然偏多 → 动态 EQ／多段压缩控制“动态”
  └─ 控制后不糊但变虚 → 低量饱和／失真补“质感”
```

## 操作原则

- 不要用一条固定低切曲线同时解决长期倾斜和局部异常。
- 动态处理只在目标频段冒出时动作，避免为了少数糊字削薄整条人声。
- 补质感的目标是生成中低频谐波与密度，不是恢复原来的低频能量。
- 每一步都做输出补偿后的旁通比较，并回到整曲检查伴奏遮蔽与咬字粗糙度。
- 频点、阈值、Ratio、Attack、Release 和饱和量都依素材而定，不使用固定通用数值。
