# 从分轨准备到削波限制完成母带闭环

## 结论

母带链应从“混音是否已经可交付”开始，而不是从选择插件开始。能在分轨解决的音量、频谱和动态冲突先回到分轨；进入总线后，再按分频动态、频谱让位、颜色、胶合、宽度、削峰和最终限制的职责逐级处理。

## 决策流程

1. 小音量、Mono 和参考曲三种条件检查人声／伴奏平衡；未通过就回到混音。
2. 只把需要独立控制的声部导成 stems，并在导出时避免削波。
3. 多段压缩只管失控频段；侧链频谱让位只管主唱与伴奏的瞬时冲突。
4. 滤波、模拟颜色和总线胶合逐项等响旁通；没有清晰收益就删掉。
5. 宽度按频段微调，低频优先稳定；用 Mono、相关度和手机播放验证。
6. Clipper 先削最短峰值，Limiter／Maximizer 再建立整体响度；用瞬态、低频、齿音和空间是否退化决定停止点。

## 边界

- 处理顺序表达的是职责依赖，不是固定插件清单。
- Clipper 加 Limiter 只是分担增益，不会自动比单级限制更透明；每一级都可能失真。
- 宽度、响度和低频中心度都应服务作品，不应追求仪表上的最大值。
- 发布平台的 True Peak 和响度要求不同，不能从单个教程推导统一目标。
