# 用七段职责链构建明亮柔顺的说唱人声

## 职责链

```text
宏观电平／常规压缩
→ 去齿音
→ 分频动态稳定
→ 宽幅音色塑形
→ 分频磁带饱和
→ 慢速光电压缩
→ 最终问题 EQ
```

这条链的价值不是插件多，而是每一级只解决一个问题：先把会移动的动态稳定下来，随后塑造综合色；再用非线性增加亮度和柔顺度，最后才清理剩余问题。若两个相邻插件持续处理同一类峰值，应删除或减轻其中一级。

## 为什么顺序重要

- 常规压缩先控制整句起伏，避免后级阈值被极端大字反复触发。
- 去齿放在提亮与饱和前，防止辅音被新增谐波再次放大。
- 多段动态只处理随时间变化的频段问题，通道条才负责长期综合色平衡。
- 磁带饱和可以增加高频可听度，同时用非线性圆化尖峰；它不同于纯高架提升。
- 光电压缩放在染色后，用慢速电平整理把主体推前并补饱满，而不是承担首轮削峰。
- 末级 EQ 只处理前面仍未解决、且能稳定复现的冗余或共振。

## 安全执行法

1. 逐级加入，每加一级都做等响旁通；响一点造成的“更好”不算改进。
2. 先写 Clip Gain／音量自动化，再设置首级压缩阈值。
3. 去齿只覆盖真正的辅音区，保留咬字；后级一旦重新变刺，先回退提亮／Drive。
4. 多段压缩从最少频段开始，只在确有独立动态问题时增加分区。
5. 通道条用宽 Q、小动作；任何固定频点都只作为搜索起点。
6. 饱和与光电压缩都从轻量开始，并检查两者是否同时在压扁峰值。
7. 最终 EQ 的每一个节点都单独旁通；删除听不出必要性的节点。

## 退出条件

- 人声在伴奏中稳定、靠前，但字头和句尾仍有自然起伏。
- 高频明亮且辅音清楚，没有砂纸感、漏风感或过度柔化。
- 小音量与单声道下主唱仍可辨，不依赖额外响度或立体声宽度伪装清晰度。
- 全链旁通并做响度匹配后，处理版的优势来自密度、综合色和位置，而不是单纯更响。
