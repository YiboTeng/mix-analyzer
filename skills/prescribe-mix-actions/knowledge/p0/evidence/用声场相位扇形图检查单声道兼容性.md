# 用声场相位扇形图检查单声道兼容性

## 判断原则

相位扇形图的价值是暴露左右声道关系的异常，而不是提供必须追求的固定形状。纵向集中通常意味着左右相关性较高；持续横向扩展可能提示反相、微小延迟或过度侧向处理，需要继续核对。

## 实用流程

1. 观察整曲与关键分轨的正常轨迹。
2. 看到异常横向形态时，定位宽化、延迟、调制、双轨或极性处理。
3. 切换单声道，听主体和低频是否变薄、偏移或消失。
4. 旁通可疑处理并等响比较；只有图形与实际兼容性同时改善时才保留修正。

## 边界

图形只是线索。某些空间层可以牺牲部分单声道一致性，核心元素则通常需要更稳定；不能为了“漂亮的图”机械压缩立体声宽度。
