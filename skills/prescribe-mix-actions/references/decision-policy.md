# 决策与证据政策

## 事实层级

- A：标准、官方手册与可重复测量；可支持工程边界和版本事实。
- B：多个独立专业来源一致并有 A/B 或本地验证；可支持默认起点。
- C：单一完整教学，含路由、前后对照与边界；只作为可试听起点。
- D：短视频单源或参数不完整；只生成实验假设。
- E：模型推断；必须明确标记并要求监听确认。

P1 的 L3 只证明指定插件版本、宿主、采样率和夹具下的行为，不证明该动作适合当前作品。P0 的短视频经验也不能因为 P1 控件已验证而自动升级为高置信度诊断。

## 顺序与冲突

默认职责顺序：

```text
参考/输入门控
→ 事件编辑与修复
→ 音高/节奏
→ 修正 EQ
→ 宏观电平
→ 峰值动态
→ 选频动态/去齿
→ 饱和与色调
→ 宽度辅助层
→ 空间/延迟
→ 人声与 Beat 融合
→ Clipper/Limiter
→ 计量与复测
```

它表达依赖关系，不是强制每个工程都使用全部层。能在上游以更小副作用解决的问题，不在下游重复处理。

强制冲突规则：

- 齿音/刺耳存在时，先控制再推饱和；饱和后复测新生谐波。
- 主唱主体保持中心；宽度优先来自 Double、Ad-lib 或返回。
- 爆破与少数峰值优先事件 Clip Gain，不默认全轨高通/重压缩。
- 参考未等响时，不据此增加高频、饱和或响度。
- 实时延迟超预算时，拒绝高延迟候选并返回编辑/低延迟退路。
- 插件版本不匹配时，保留能力级建议，但抑制精确控件映射。
- 未提供当前 Inventory/版本时，默认抑制精确控件；显式信任快照也必须显示未实时重确认警告。
- 单参考没有离散度，不计算稳健偏差或离群分数；只允许低置信度 `conditional-hypothesis`，并强制先做等响、同职责段落的重复 A/B。
- Mono fold loss 数值更低/更负才表示损失更大；Target 损失更小不得生成 `mono_translation_risk`。
- `manual` 是独立输入模式，不是其他模式的通配符；每张卡必须同时通过 mode 与 scope。
- Master-only 只能给总线安全的宽带判别与小幅起点，禁止套用人声高通、单轨压缩或从 Master 反推 Stem 参数。
- 低 PLR/低 Crest 进入恢复动态处方，不再追加压缩；低频/Presence 的高低方向使用不同诊断卡。
- Host 延迟、Lookahead 与音乐性 Delay 必须分字段；未知 Host 延迟在实时模式默认拒绝。

## 停止条件

每项动作必须能撤回，并同时满足：

- 等响旁路仍有收益；
- 全混音优于 Solo；
- 问题指标改善且关键副作用没有恶化；
- Mono、峰值、延迟或编码检查未越界；
- 继续增加强度只带来更响、变薄、失真、抽吸或声像不稳时停止。
