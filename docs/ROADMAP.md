# 分阶段路线

## P0.1｜当前版本

- 双模式旧指标兼容。
- canonical diagnosis/treatment schema。
- 28 张高频决策卡，含严格模式/Scope、方向恢复和 Master-only 安全分支。
- 参考门控、多诊断证据合并、互斥方向求解、Top-K 后链序，以及版本/宿主/格式/采样率/模式化延迟过滤。
- JSON 与 Markdown 处方。

验收：Schema、47 项单元/集成/反例测试、4 个 Skill 验证和 Plugin 验证通过。

## P0.2｜标定与因果消歧

- 建立静音、极短、单/双声道、不同采样率和 1/2/3/5 参考 fixture。
- 合成 EQ、压缩、削波、延迟、调制、混响等可控差异。
- 用带标签音节/短语建立爆破、齿音、呼吸、点击、房间、动态和修音事件检测。
- 把卡内 `calibration_required` 分批转成版本化阈值。
- 加入 dry vocal 与 full mix 完全分开的阈值与因果测试。

## P1.1｜参数 Recipe 层

- 把当前 Markdown 中提取的句子升级为结构化字段：unit、min/max、start_range、step、automation、version、mode。
- 为 40 款插件建立控件名称/范围/默认值/参数 ID 的版本表。
- 新增 SoundToys L2→L3、StandardCLIP 可用性复核及缺口插件。
- 增量版本复测，不继承旧版确定性映射。

## P2｜完整工程规划

- 输入 Vocal、Beat、Stems、BPM、Key、段落与审美目标。
- 生成编辑清单、主链、返回、自动化、总线、母带与导出计划。
- 先生成可审计工程计划，不直接改 DAW。
- 使用真实用户工程把动作升级到 L4。

## P3｜受控 DAW 执行

- 单独授权后才控制 Studio One 或插件宿主。
- 通过参数 ID/预设/路由 API 执行小步操作。
- 每一步渲染、等响 A/B、回滚、指标复测和用户确认。
- 将动作日志与音频版本绑定。

## P4｜完整混音代理

- 多轨编辑、自动化、Stem/Bus/FX/Master 全流程。
- 多目标优化：风格、清晰度、冲击力、空间、响度和交付规格。
- “格莱美级”只能作为审美目标，不作为可客观保证的验收声明；验收仍以参考、盲听、技术指标和用户判断为准。
